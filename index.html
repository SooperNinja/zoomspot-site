How to use ZoomSpot

  1. Open an ordinary website tab and click ZoomSpot.
  2. Choose Select an area and drag around the part you want to enlarge.
  3. Resize the viewing window. Keep the source page open.
  4. Close the view to stop capture.

Useful controls

Arrow keys move the crop. +/− adjust zoom. R resets the selection. F opens fullscreen. P requests Picture-in-Picture. Use the save button to name an area for later.

Compatibility

Desktop Chrome 116+. Chrome's internal pages and restricted pages are not supported. Some protected video can remain black. The interface is in English.
